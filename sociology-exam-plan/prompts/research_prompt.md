# Research Phase Prompt Template

> 用于阶段一的各项研究任务。调用 deep-research / WebSearch / cnki-search 时使用。

## 官方信息搜索 Prompt

```
搜索南京大学社会学院2027级（2026年12月初试）社会学专业硕士研究生招生信息。

请整理以下内容：
1. 招生简章链接及关键信息（招生人数、报考条件、考试科目）
2. 参考书目（官方指定或历年默认）
3. 历年报录比（如有公开数据）
4. 导师名单及研究方向
5. 2025→2026→2027 年的变化（参考书/考试范围/招生人数）
6. 复试信息（复试比例、复试内容、是否有笔试）

搜索范围：
- nju.edu.cn 域名下的官方公告
- 南京大学研究生院官网
- 南京大学社会学院官网
- 研招网

每个信息标注来源 URL 和获取日期。无法确认的信息标注 [待验证]。
```

## 真题搜集与分析 Prompt

```
搜集南京大学社会学考研近15年（2011-2026）真题，科目代码 614（社会学理论）和 837（社会学方法）。

对每道真题进行以下标注：
- 年份、题型（名词解释/简答/论述/计算题/研究设计）、分值
- 所属知识模块（经典社会学理论/现代社会学理论/当代社会学理论/社会学方法/社会统计学/Stata）
- 具体知识点标签（如"韦伯-理解社会学""涂尔干-社会事实""风笑天-问卷设计"）
- 是否为热点题/开放题

统计产出：
1. 知识点频率排行榜（按出现次数降序）
2. 各模块分值占比变化趋势（以3年为单位）
3. "必考"知识点清单（出现≥5次或近3年连续出现）
4. "冷门"知识点清单（近10年未出现但在考纲内）
5. 题型演变趋势分析
6. 重复规律分析（同一知识点隔几年重复？）

如果某年真题无法获取，标注该年份为 [缺失]，并说明尝试过的搜索渠道。
```

## 热点整理 Prompt

```
整理2025-2026年中国社会学领域的热点议题，并分析与南京大学社会学考研的潜在关联。

热点领域（不限于此）：
- 数字社会与AI治理
- 平台经济与劳动形态变迁
- 人口老龄化与生育政策
- 城乡融合发展
- 基层社会治理
- 共同富裕与社会分层
- 风险社会与不确定性
- 数字民族志与计算方法
- 家庭变迁与代际关系
- 环境社会学/生态文明

对每个热点：
1. 简要描述热点背景（100字）
2. 映射到社会学理论（可以联系哪些经典/现代/当代理论？）
3. 关联南大导师研究（哪些导师在做相关方向？）
4. 预判可能的命题角度（名词解释/简答/论述分别可以怎么出？）
5. 推荐关键文献（中英文各1-2篇，标注来源）

搜索范围：
- 近2年 CSSCI 社会学核心期刊（社会学研究、社会、社会学评论等）
- 中国社会学会2025/2026年学术年会主题
- 国家社科基金社会学类立项题目
- 南大社会学院导师近3年发表
```
