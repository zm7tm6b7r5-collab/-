# Analysis & Synthesis Prompt Template

> 用于阶段二（知识体系整理）和阶段四（复习系统设计）。将研究结果转化为结构化知识。

## 高频考点提取 Prompt

```
根据以下真题分析结果，提取高频考点并建立知识体系。

输入：01_research/04_past_exams_analysis.md（真题频率统计）
输出格式要求：

### 按模块分组

每个考点包含：
| 考点 | 重要度 | 出现次数 | 最近出现 | 题型分布 | 答题要点 |
|------|--------|---------|---------|---------|---------|

重要度标准：
- ⭐⭐⭐ 必考：近15年出现≥5次，或近3年连续出现
- ⭐⭐ 高频：出现3-4次，或间或出现但分值高
- ⭐ 低频但可能：近10年未出现但属于考纲核心，新教材新增内容

### 跨模块关联
标注可以串联复习的知识点组合（如"韦伯-理性化→现代性批判→风险社会"）
```

## 理论-人物-概念映射 Prompt

```
建立社会学理论的三维知识网络。

对每个高频理论：
1. 明确代表人物（含生卒年、学派归属）
2. 核心命题（一句话概括）
3. 关键概念（3-5个，每个一句话）
4. 与其他理论的对话关系（谁继承了他？他批评了谁？谁批评了他？）
5. 现实应用举例（用该理论解释一个当代现象）
6. 真题链接（哪年考过，什么题型）

输出为互链结构：
- 理论 → 人物 → 概念 → 真题
- 理论 → 对立理论 → 综合视角
```

## 经验帖有效性评估 Prompt

```
评估以下考研经验帖建议的有效性。

对每条建议，从三个维度判断：
1. **学习科学依据**：是否有认知心理学/学习科学的研究支持？
   - 有强证据支持（如间隔重复、主动回忆）→ 高可信
   - 有间接支持或逻辑合理 → 中可信
   - 与学习科学证据矛盾 → 低可信
2. **多源交叉验证**：该建议在多少独立来源中出现？
   - ≥5个独立来源 → 高可信
   - 2-4个 → 中可信
   - 单一来源 → 低可信
3. **幸存者偏差风险**：该建议是否只适用于成功者？
   - "我这样做考上了" ≠ 这样做有效
   - 需要对照：没这样做的人也考上/这样做了也没考上

最终分类：
- ✅ 可信建议（强证据 + 多源验证）
- ⚠️ 待验证建议（逻辑合理但缺乏证据）
- ❌ 不可信建议（与证据矛盾或明显幸存者偏差）
- 🔀 矛盾建议（不同来源说法相反）
```
