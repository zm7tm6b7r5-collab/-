# Plan Generation Prompt Template

> 用于阶段三（学习计划生成）和阶段五（最终方案汇总）。

## 时间倒推计划 Prompt

```
根据以下参数生成时间倒推的学习计划：

### 输入参数
- 考试日期：YYYY-MM-DD
- 剩余天数：X 天
- 每日可用时间：X 小时（工作日）/ X 小时（周末）
- 已有基础：[描述]
- 参考书数量：6 本

### 阶段划分原则
1. 每个阶段必须有明确的"完成标准"（可验证）
2. 阶段间有缓冲期（应对突发情况）
3. 越接近考试，输出练习占比越高
4. 最后 2 周回归教材，不做新题

### 每个阶段计划需包含
- 起止日期与总天数
- 核心任务（3-5 条）
- 每周任务分解
- 输入材料清单（读什么）
- 输出要求（产出什么、多少量）
- 完成检测方式（做一套真题？默写框架？）
- 本阶段常见误区提醒

### 特殊约束
- 大三下学期可能有课程考试，需预留复习时间
- 政治复习通常 9 月开始（参考常规节奏）
- 英语持续进行，每天不少于 30 分钟
```

## 每日模板生成 Prompt

```
设计一个可复用的每日学习模板。

约束条件：
- 工作日可用 X 小时，周末可用 X 小时
- 需覆盖：专业课（理论+方法）、英语、政治（9月后加入）
- 每天必须包含：新学 + 复习 + 输出练习
- 每天结束时 10 分钟复盘

模板格式：
| 时间段 | 时长 | 任务类型 | 具体内容 | 备注 |
|--------|------|---------|---------|------|
| 8:00-9:30 | 90min | 新学-理论 | 精读周晓虹第X章 | 配合笔记 |
| ... | ... | ... | ... | ... |

工作日模板和周末模板分别设计。
```

## 最终方案汇总 Prompt

```
将所有阶段的研究和计划成果，整合为一份完整方案。

结构：
1. **备考总览**（1-2页）
   - 目标院校/专业/分数
   - 考试科目与分值
   - 总时间线（从今天到复试结束）
   - 核心资源清单

2. **各阶段计划**（主体）
   - 每阶段1-2页
   - 含目标、任务、输入、输出、检测标准

3. **每日执行系统**
   - 工作日/周末模板
   - 周复盘模板
   - 进度追踪方法

4. **工具链配置**
   - Obsidian 目录结构建议
   - Anki 制卡频率建议
   - Claude Code / exam-review 使用时机

5. **应急预案**
   - 进度落后2周的调整方案
   - 某阶段检测不合格的补救措施
   - 考前一个月的冲刺节奏

要求：
- 可直接执行（不需要再解释）
- 每个建议配"为什么"
- 总字数不限，以覆盖完整为准
```
