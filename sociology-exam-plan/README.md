# 社会学考研 Research Agent 项目

> 南京大学社会学考研全流程研究方案——研究驱动，证据优先，分阶段输出。

## 这是什么？

一个**研究型 Agent 项目**，不是一次性生成的模板计划。

Claude Code 在此目录下运行时，自动切换为"社会学考研研究助理"模式（见 [CLAUDE.md](CLAUDE.md)），按照五阶段工作流：
1. 全面研究（考纲/真题/热点/经验帖）
2. 知识体系整理（高频考点/理论/人物）
3. 学习计划生成（7 阶段 + 月/周/日计划）
4. 复习记忆系统（背书/艾宾浩斯/Anki/Obsidian）
5. 汇总最终方案

## 目录结构

```
sociology-exam-plan/
├── CLAUDE.md              ← Agent 的"大脑"（角色、工作流、规范）
├── _config.yml            ← 用户画像与考试参数
├── README.md              ← 本文件
│
├── 01_research/           ← 阶段一：研究文档（考纲/真题/热点/经验帖）
├── 02_knowledge/          ← 阶段二：知识体系（高频考点/理论/人物）
├── 03_plan/               ← 阶段三：学习计划（7阶段+月/周/日）
├── 04_review/             ← 阶段四：复习系统（背书/Anki/Obsidian）
├── 05_output/             ← 最终输出（总方案）
└── prompts/               ← Agent 专用 Prompt 模板
```

## 使用方法

1. 在此目录下打开 Claude Code（或 `cd` 到此目录）
2. Agent 自动读取 CLAUDE.md，切换为研究助理模式
3. 按阶段推进：说"开始阶段一"或指定具体研究任务
4. 每份文档独立维护，新信息到来时只更新相关文档

## 与现有工具的关系

| 工具 | 关系 |
|------|------|
| **本项目** | 制定计划（考前研究 + 策略设计） |
| exam-review | 执行计划（日常抽测 + 真题模拟） |
| Anki | 记忆巩固（知识点→抽认卡） |
| Obsidian | 知识存储（长期笔记管理） |
| kaoyan_daily.py | 英语外刊精选（独立系统） |
