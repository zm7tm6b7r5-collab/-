## 四、837 计算题高频考点（基于 2000-2025 真题）

*⚠️ 计算题是南大社会学方法的核心区分度来源，必须动手算。*

|  |  |  |  |
| --- | --- | --- | --- |
| **重要性** | **考点** | **真题出现年份** | **核心公式** |
| ⭐⭐⭐ | 离散系数比较 | 2007, 2012 | CV = S / X̄ |
| ⭐⭐⭐ | 置信区间估计 | 2006, 2008, 2013 | X̄ ± Z(α/2) × S/√n |
| ⭐⭐⭐ | 回归分析与解读 | 2013, 2014, 2025（含多元回归） | y = a + bx；R² 解读 |
| ⭐⭐⭐ | 样本量确定 | 2025, 2012 | n = Z²S² / E² |
| ⭐⭐ | 比例置信区间 | 2008 | p ± Z × √[p(1-p)/n] |
| ⭐⭐ | 集中/离散趋势计算 | 2006, 2009, 2014 | 组距数据求均值/中位数/众数 |
| ⭐⭐ | 方差分析（F检验） | 2020 | F = MSB / MSW |
| ⭐⭐ | 卡方检验 | 2006, 2008 | χ² = Σ[(O-E)²/E] |
| ⭐⭐ | 抽样分布/中心极限定理 | 2020 | σ\_x̄ = σ/√n |

## 九、备考策略

### 三梯队复习优先级

**第一梯队（必须烂熟于心，⭐⭐⭐）：**

* 布迪厄（场域/惯习/资本/实践理论）—— 近年最热
* 吉登斯（结构二重性/现代性）—— 名词解释+简答双杀
* 涂尔干（团结类型/自杀论/失范）—— 每年必考
* 韦伯（理性化/权威类型/科层制）—— 每年必考
* 哈贝马斯（沟通行动理论）—— 论述题定期出现
* 帕森斯 + 默顿（结构功能主义）—— 基础中的基础

**第二梯队（重要但可适当精简，⭐⭐）：**

* 齐美尔（形式社会学）、福柯（权力/规训）、马克思（异化/阶级）
* 科塞（冲突理论）、霍曼斯/布劳（交换理论）、戈夫曼（拟剧论）
* 埃利亚斯（文明化）—— 近年升温

**第三梯队（了解基本概念，⭐）：**

* 孔德、斯宾塞、舒茨、加芬克尔、法兰克福学派

### 复习方法论

1. **真题至少做 3 遍**：2000-2024 年真题有大量重复考点
2. **做系统笔记**：以侯钧生为主线，周晓虹补充脉络，围绕理论家整理独立卡片
3. **理论与现实结合**：论述题必考"结合实际评析"，平时积累社会热点用理论解释
4. **中西结合**：南大特色考点，儒家思想与西方社会学理论的对话
5. **计算题动手算**：离散系数、置信区间、回归分析、样本量确定是必练题型
6. **前沿理论**：2026 新增郑作彧教材，权重必定上升
