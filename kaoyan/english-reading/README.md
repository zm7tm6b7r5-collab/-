# 考研英语 · 每日外刊精读

> 每天早上由 Codex 定时任务自动执行：检索当天重点外刊文章 → 逐句拆解长难句 → 梳理段落逻辑 → 生成精读报告并推送。

## 目录结构

```
kaoyan/english-reading/
├── README.md                ← 本文件（工作流说明）
├── daily_prompt.md          ← 定时任务每天执行的完整指令（任务的核心）
├── hot-topic-articles.md    ← 近一年命题热点外刊文章库（持续积累，每日维护）
├── archive/                 ← 每日精读报告存档（文件名 = 日期，如 2026-08-03.md）
└── .gitkeep
```

## 每天的输出物

每天 18:30 运行一次，产出两样东西：

1. **热点文章库更新**（`hot-topic-articles.md`）：深度调研 1–2 个近一年命题热点，补充/去重/标记外刊文章；
2. **精读报告**（`archive/<YYYY-MM-DD>.md`）：从热点库选 1 篇做完整精读，包含：

- 文章信息（标题 / 来源 / 日期 / 链接 / 题材分类 / 词数）
- 一句话主旨
- 段落逻辑梳理（每段功能 + 段间衔接 + 全文论证结构）
- 长难句逐句拆解（主干 → 成分标注 → 翻译 → 语法点 → 仿写）
- 核心词汇与表达（8–15 个，含例句）
- 命题角度预测（主旨 / 细节 / 推断 / 态度 / 词义题示例）
- 今日学习建议（可复习词汇 + 可套用作文句型）

## 调研与选题规则（写死在 daily_prompt.md 中）

- **来源**：考研英语真题主要外刊来源 —— The Economist、The Guardian、Scientific American、Nature、The Atlantic、Time、Newsweek、BBC、NYT、WaPo 等
- **难度**：词汇量 5500 上下、长难句密度与真题阅读一/二接近
- **篇幅**：400–600 词（接近考研阅读一篇）
- **时间窗**：近一年（过去 365 天）的命题热点文章，不只追当天新闻
- **热点依据**：项目根目录《2027考研英语命题热点与新增词汇补充.md》的 TOP10 命题热点清单
- **轮换**：热点逐个深挖（约 1–2 周覆盖一轮）+ 经济科技 / 社会生活题材交替精读

## 使用方法

1. 在 Codex 桌面应用中创建定时任务（详见下方「定时任务参数」）。
2. 任务每天自动运行：新线程 → 读取 `daily_prompt.md` → 执行检索与写作 → 存档 + 推送摘要。
3. 手动触发：把 `daily_prompt.md` 内容发给任意 Codex 会话即可。

## 定时任务参数（创建时照抄）

| 参数 | 值 |
|------|-----|
| 任务名称 | 考研英语每日外刊精读 |
| 触发时间 | 每天 18:30（已确认） |
| 运行目录 | `C:\Users\AUSU\Documents\trae_projects\cc` |
| 指令来源 | `kaoyan/english-reading/daily_prompt.md`（内容粘进任务） |
| 每日篇数 | 1 篇 |
| 推送方式 | 应用内新任务推送摘要 + 报告存 `archive/`（默认） |

> 注意：定时任务每次运行会在新线程中执行，任务本身只负责"每天这个时间启动"；执行逻辑全部由 `daily_prompt.md` 驱动。
